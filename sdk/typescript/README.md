# @flanksource/mission-control-sdk

Type-safe TypeScript client for the [Mission Control](https://flanksource.com)
PostgREST API. Generated from the live PostgREST schema, enriched with Go-doc
descriptions and RBAC metadata sourced from the
[duty](https://github.com/flanksource/duty) repository.

## Install

```bash
npm install @flanksource/mission-control-sdk openapi-fetch
```

`openapi-fetch` is a peer dependency so consumers stay in control of the
runtime client version.

## Usage

```ts
import { createMissionControlClient } from "@flanksource/mission-control-sdk";

const mc = createMissionControlClient({
  baseUrl: "https://mission-control.example.com/db",
  token: process.env.MC_TOKEN,
});

const { data, error } = await mc.GET("/config_items", {
  params: { query: { limit: "10", select: "id,name,type" } },
});
```

All endpoints, query parameters, and response shapes are inferred from the
OpenAPI 3.1 spec shipped with the package (`./openapi.json`).

### Direct schema access

```ts
import type { ConfigItem, components } from "@flanksource/mission-control-sdk";

type Notification = components["schemas"]["notifications"];

function summarise(items: ConfigItem[]) { ... }
```

### Auth modes

The default client adds `Authorization: Bearer <token>` when `token` is set.
Use the `headers` option for any other scheme:

```ts
createMissionControlClient({
  baseUrl: "...",
  headers: { "X-API-Token": apiToken },
});
```

## Versioning

The package version mirrors the duty Go-module tag it was generated from.

## Regenerating

The package is regenerated by running `make gen-openapi` in the
[duty](https://github.com/flanksource/duty) repository. The generator boots an
embedded Postgres, applies migrations, starts PostgREST, fetches the live
spec, enriches it, and rewrites `src/types.ts` and `openapi.json`.
